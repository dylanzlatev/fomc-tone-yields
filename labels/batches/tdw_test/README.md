# tdw_test batches (not committed)

The `batch_NNNN.jsonl` files and `manifest.csv` in this folder are generated by
`python -m ftyields.label.tdw` from the **test split of the Trillion Dollar Words
dataset** (Hugging Face `gtfintechlab/fomc_communication`; Shah, Paturi and Chava, 2023).

The dataset is licensed **CC BY-NC 4.0** (attribution, non-commercial). Because the
batches contain the dataset's sentences, they are listed in `.gitignore` and must not be
committed or redistributed. Only this README is tracked. Rebuild the files at any time
with the command above (the download is recorded in `data/raw/MANIFEST.csv`).

Items are `{"id": "tdw_test_<row>", "prev_text": "", "text": <sentence>}` (`<row>` is the
zero-padded 0-based row of the sentence in `test.csv`; the file's own `index` column is
not unique), 250 per batch, in id order. Test sentences that also appear in the train split are dropped first.
